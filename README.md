A modern realtime chat application built with Next.js (TypeScript), TailwindCSS, and Socket.IO.
Users can create rooms, join them, and chat instantly in realtime with a clean UI.


🚀 Features

🔑 Create & join chat rooms

⚡ Realtime messaging powered by Socket.IO

🎨 Modern, responsive UI with TailwindCSS

🛡️ Type-safe codebase with TypeScript

🌐 Deployed & production-ready
